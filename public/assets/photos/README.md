# Satwika OS photo assets

The Photos application uses these eight supplied PNG files unchanged:

- `car_sat.png`
- `deep_sat.png`
- `idk_sat_1.png`
- `idk_sat_2.png`
- `jat_sat_1.png`
- `jat_sat_2.png`
- `junny_pixell.png`
- `pixel_satt_1.png`

Gallery order and short titles are configured in `src/config/photos.ts`. Each
entry points to one unique source image.
